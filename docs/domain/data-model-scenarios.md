## 1. 执行前提与证据

使用合成的两租户、同租户两门店、至少两房型和三间房。每个测试保存源码/迁移版本、PostgreSQL 主版本与镜像摘要、启用的 DEC 分支、政策时区、测试时钟、命令摘要/操作 ID、事务边界、锁获取屏障、最终数据快照与客户端结果。

数据库约束负例同时使用直接 SQL 与业务入口验证：直接 SQL 测数据库兜底，业务入口测授权和联合状态。并发使用至少两个独立连接与确定性屏障，不用随意 sleep 假定产生竞争。触发预期错误后核对整个事务回滚，无失败操作的订单、占用、流水、审计或事件残留。
